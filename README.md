# Fresh Coffee - Frontend

Aplicación web para realizar pedidos en un quiosco de comida.

## ⚛️ Tecnologías
- React
- TailwindCSS
- Context API
- SWR

## 🔗 Backend API
- https://github.com/Luismy-182/fresh-coffee-backend

## ⚙️ Instalación
- npm install
- npm run dev

## ✨ Funcionalidades
- Registro y login
- Catálogo de productos
- Creación de pedidos
- Actualización en tiempo real
